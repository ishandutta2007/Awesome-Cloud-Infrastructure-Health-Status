## 🏢 SaaS / Commercial Platforms

The cloud infrastructure health and status market spans **cloud provider native health dashboards** (AWS Health, Azure Service Health, Google Cloud Status) that provide **free, personalized visibility** into service disruptions affecting your specific resources, and **third-party monitoring platforms** (Statuspage, Better Uptime, Datadog Synthetic) that charge **per monitor, per subscriber, or per test execution**. **AWS Health** is **free** and provides **personalized service health events** via the AWS Health Dashboard, with programmatic access through the **AWS Health API** (requires Business or Enterprise Support) . **Atlassian Statuspage** offers a **free tier for 25 subscribers** and **1 status page**, with paid plans starting at **$29/month** . **Better Uptime** (Better Stack) provides a **free tier with 10 monitors and 3-minute check intervals**, with paid plans from **$18/month** . **Datadog Synthetic Monitoring** charges **$5 per 10,000 API test runs** or **$12 per 1,000 browser test runs**, plus **$0.50 per 10,000 API test runs for additional locations** . **Pingdom** starts at **$10/month for 10 uptime monitors** with **1-minute check intervals** on higher tiers . **UptimeRobot** offers a **free tier with 50 monitors and 5-minute checks**, with paid plans from **$7/month** . **Instatus** provides a **free tier with unlimited subscribers and 1 status page**, with paid plans from **$20/month** . **StatusCake** starts at **$24.99/month for 10 uptime monitors** with **1-minute checks** . **New Relic Synthetics** charges **$0.00125 per synthetic check** (first 100,000 checks free) . **ThousandEyes** uses **custom enterprise pricing** with deployment through AWS Marketplace .

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Uptime Kuma](https://github.com/louislam/uptime-kuma)** [![Stars](https://img.shields.io/github/stars/louislam/uptime-kuma?style=social&color=white)](https://github.com/louislam/uptime-kuma/stargazers)  
  **Self-hosted website monitoring tool like Uptime Robot**, MIT licensed. **The most popular open-source uptime monitor** — **Docker/Nodejs** deployment. Monitoring for **HTTP(s), TCP, Ping, DNS, and more**. **Notification integrations with 90+ services via Apprise**. **Status pages** and multi-language support. **The de facto standard for self-hosted uptime monitoring**. 📈

- **[Gatus](https://github.com/TwiN/gatus)** [![Stars](https://img.shields.io/github/stars/TwiN/gatus?style=social&color=white)](https://github.com/TwiN/gatus/stargazers)  
  **Automated service health dashboard**, Apache-2.0 licensed. **Docker/K8S** deployment. **Condition-based health checks** — define success criteria using **status codes, response time, body content, and certificate expiry**. **Alerting** via Slack, PagerDuty, Discord, Telegram, and more. **Status page** generation included. **The most flexible open-source health dashboard**. ⚙️

- **[Kener](https://github.com/rajnandan1/kener)** [![Stars](https://img.shields.io/github/stars/rajnandan1/kener?style=social&color=white)](https://github.com/rajnandan1/kener/stargazers)  
  **Stunning self-hosted status pages**, MIT licensed. **Built with SvelteKit and NodeJS**. **Monitoring and tracking** — HTTP endpoint polling or push data via REST API. **Cron-based scheduling** (minimum per minute). **Incident management** with communication APIs. **Customization** — badges, custom domains, iframe/widget embedding, light/dark theme, i18n. **Docker deployment** with pre-built image. **Beautifully crafted status pages without the enterprise overhead**. 📊

- **[Pingvin Share](https://github.com/stonith404/pingvin-share)** [![Stars](https://img.shields.io/github/stars/stonith404/pingvin-share?style=social&color=white)](https://github.com/stonith404/pingvin-share/stargazers)  
  **Self-hosted file sharing platform**, BSD-3-Clause licensed. **~4k+ stars**. **Share files securely** with expiration dates and download limits. **Not a monitoring tool** — included here for completeness of the self-hosted infrastructure ecosystem. 🐧

- **[StatPing.ng](https://github.com/statping-ng/statping-ng)** [![Stars](https://img.shields.io/github/stars/statping-ng/statping-ng?style=social&color=white)](https://github.com/statping-ng/statping-ng/stargazers)  
  **Easy-to-use status page for websites and applications**, GPL-3.0 licensed. **Docker/Go** deployment. **Automatically fetches application status** and renders a beautiful status page. **Notification support** for multiple channels. **Database options**: SQLite, MySQL, PostgreSQL. **The most mature open-source status page generator**. 🎯

- **[Cachet](https://github.com/cachethq/cachet)** [![Stars](https://img.shields.io/github/stars/cachethq/cachet?style=social&color=white)](https://github.com/cachethq/cachet/stargazers)  
  **Open-source status page system**, MIT licensed. **~14k+ stars**. **PHP/Laravel** based. **Incident management, scheduled maintenance, and subscriber notifications**. **The original open-source Statuspage alternative**. 🏛️

- **[Uptime](https://github.com/uptime-project/uptime)** [![Stars](https://img.shields.io/github/stars/uptime-project/uptime?style=social&color=white)](https://github.com/uptime-project/uptime/stargazers)  
  **Remote monitoring application using Node.js, MongoDB, and Twitter Bootstrap**, MIT licensed. **Simple and lightweight** uptime monitoring. **The precursor to modern open-source monitoring tools**. ⏰

- **[Monika](https://github.com/monika-dev/monika)** [![Stars](https://img.shields.io/github/stars/monika-dev/monika?style=social&color=white)](https://github.com/monika-dev/monika/stargazers)  
  **Synthetic monitoring tool**, MIT licensed. **Command-line based monitoring** — check URLs, APIs, and services from the terminal. **YAML configuration** for monitors. **Notifications** via multiple channels. **Lightweight alternative** to enterprise synthetic monitoring. 🎯

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement. ℹ️
- **AWS Health Dashboard is free** for all AWS customers, but **AWS Health API access requires Business or Enterprise Support** . **EventBridge integration** is available for automated response workflows.
- **Datadog Synthetic Monitoring charges separately for API and browser tests**: **$5 per 10,000 API test runs**, **$12 per 1,000 browser test runs**, and **$0.50 per 10,000 additional API test runs for extra locations** . **Model your test frequency and location count** before committing.
- **UptimeRobot's free tier is the most generous** — **50 monitors with 5-minute checks forever** . **Instatus offers unlimited subscribers on free tier** — ideal for public status pages . **Better Uptime offers 10 monitors free** with **3-minute checks** .
- **Open-source tools (Uptime Kuma, Gatus, Kener, Cachet) are not turnkey** — they require **deployment, configuration, and ongoing maintenance**. **Uptime Kuma supports 90+ notification services** via Apprise but requires manual setup for each channel .
- **Status page tools are not monitoring tools** — **Statuspage and Instatus tell your users what's happening; they don't detect problems**. **Pair with a monitoring solution** (Datadog Synthetic, UptimeRobot, or open-source alternatives) for complete coverage. 🏥
